# DESIGN SYSTEM - WEB SHOE STORE

## 1. COLORS

### Primary Colors
```css
--primary-red: #DC3E37;      /* Main brand color - buttons, links, accents */
--secondary-orange: #F2965B;  /* Hover states, secondary actions */
--dark-text: #322A2A;         /* Primary text color */
--light-bg: #EFEBEA;          /* Background, cards */
```

### Neutral Colors
```css
--white: #FFFFFF;
--black: #000000;
--gray-100: #F8F9FA;
--gray-200: #E9ECEF;
--gray-300: #DEE2E6;
--gray-400: #CED4DA;
--gray-500: #ADB5BD;
--gray-600: #6C757D;
--gray-700: #495057;
--gray-800: #343A40;
--gray-900: #212529;
```

### Semantic Colors
```css
--success: #28A745;
--warning: #FFC107;
--danger: #DC3545;
--info: #17A2B8;
```

### Usage Guidelines
- **Primary Red (#DC3E37)**: Use for primary CTAs, active states, important links
- **Secondary Orange (#F2965B)**: Use for hover states, secondary buttons, highlights
- **Dark Text (#322A2A)**: Use for all body text, headings
- **Light BG (#EFEBEA)**: Use for card backgrounds, section backgrounds, disabled states

## 6. TRANSITIONS & ANIMATIONS

### Standard Transitions
```css
/* Fast (Hover effects) */
transition: all 0.2s ease;

/* Medium (State changes) */
transition: all 0.3s ease;

/* Slow (Slide, expand) */
transition: all 0.4s ease;
```

### Specific Transitions
```css
/* Color Changes */
transition: color 0.2s ease, background-color 0.2s ease, border-color 0.2s ease;

/* Transform (Scale, Rotate) */
transition: transform 0.2s ease;

/* Opacity */
transition: opacity 0.3s ease;

/* Height (Collapsible) */
transition: max-height 0.4s ease;
```

### Animation Examples

## 12. RESPONSIVE BREAKPOINTS

```css
/* Mobile First Approach */

/* Extra Small (< 576px) - Default */
/* Small (≥ 576px) */
@media (min-width: 576px) { }

/* Medium (≥ 768px) */
@media (min-width: 768px) { }

/* Large (≥ 992px) */
@media (min-width: 992px) { }

/* Extra Large (≥ 1200px) */
@media (min-width: 1200px) { }

/* XXL (≥ 1400px) */
@media (min-width: 1400px) { }
```

### Responsive Typography
```css
/* Mobile */
h1 { font-size: 1.75rem; } /* 28px */
h2 { font-size: 1.5rem; }  /* 24px */
body { font-size: 0.9rem; } /* 14.4px */

/* Tablet and Up */
@media (min-width: 768px) {
    h1 { font-size: 2.5rem; }  /* 40px */
    h2 { font-size: 2rem; }    /* 32px */
    body { font-size: 1rem; }  /* 16px */
}
```

### Responsive Spacing
```css
/* Mobile */
.container { padding: 12px; }
.section { margin-bottom: 24px; }

/* Tablet and Up */
@media (min-width: 768px) {
    .container { padding: 16px; }
    .section { margin-bottom: 40px; }
}

/* Desktop */
@media (min-width: 1200px) {
    .container { padding: 24px; }
    .section { margin-bottom: 60px; }
}
```

## 16. ACCESSIBILITY

### Focus Indicators
```css
/* Visible focus for keyboard navigation */
*:focus-visible {
    outline: 2px solid var(--primary-red);
    outline-offset: 2px;
}
```

### Color Contrast
- **Text on White**: Use --dark-text (#322A2A) for 4.5:1 contrast ratio
- **White Text on Primary Red**: Meets WCAG AA standard
- **Links**: Minimum 3:1 contrast with surrounding text

### Screen Reader Support
```html
<!-- Use semantic HTML -->
<button aria-label="Close">
    <i class="fas fa-times"></i>
</button>

<!-- Use ARIA when needed -->
<div role="button" tabindex="0" aria-pressed="false">
    Toggle
</div>
```

### Skip Links

## USAGE CHECKLIST

When creating or updating a page, ensure:

### Colors
- [ ] Use CSS variables from color palette
- [ ] Primary red (#DC3E37) for CTAs and links
- [ ] Secondary orange (#F2965B) for hover states
- [ ] Dark text (#322A2A) for all body text
- [ ] Light bg (#EFEBEA) for cards and sections

### Typography
- [ ] Poppins font family loaded
- [ ] Font sizes match the scale (0.75rem to 2.5rem)
- [ ] Line heights are appropriate (1.2-1.6)
- [ ] Font weights match purpose (400 for body, 500-600 for headings, 700 for emphasis)

### Spacing
- [ ] Use 4px base unit (multiples of 4)
- [ ] Consistent padding in components
- [ ] Appropriate margins between sections
- [ ] Compact spacing for dense UI (filters, badges)

### Borders & Radius
- [ ] Thin borders (1px) for minimal look
- [ ] Border radius: 6px (small), 8px (medium), 12px (large)
- [ ] Dashed borders for secondary actions (Show More)

### Shadows
- [ ] Subtle shadows (opacity 0.05-0.12)
- [ ] Hover shadows use primary red tint
- [ ] Cards have shadow-sm by default
- [ ] Dropdowns and modals have shadow-md or shadow-lg

### Transitions
- [ ] All interactive elements have transitions
- [ ] 0.2s for fast (hover, color changes)
- [ ] 0.3s for medium (state changes)
- [ ] 0.4s for slow (expand, collapse)

### Buttons
- [ ] Primary buttons: red background, white text
- [ ] Secondary buttons: white background, red border
- [ ] Compact buttons for filters
- [ ] Hover states change color and add shadow
- [ ] Active states have solid background

### Cards
- [ ] White background
- [ ] 12px border radius
- [ ] 16px padding
- [ ] shadow-sm by default
- [ ] Hover effect: shadow-hover + translateY(-4px)

### Forms
- [ ] 1px border, gray-300 color
- [ ] 8px border radius
- [ ] Focus state: red border + shadow ring
- [ ] Placeholder text is gray-500
- [ ] Disabled state: light-bg background

### Responsive
- [ ] Mobile-first approach
- [ ] Test on 576px, 768px, 992px, 1200px breakpoints
- [ ] Typography scales appropriately
- [ ] Grid columns adjust (1→2→3→4)
- [ ] Spacing increases on larger screens

### Accessibility
- [ ] Focus indicators visible
- [ ] Color contrast meets WCAG AA
- [ ] ARIA labels on icon-only buttons
- [ ] Semantic HTML (button, nav, main, etc.)
- [ ] Keyboard navigation works
