🔄 Clear Cache & Reload

Để thấy được thay đổi UI mới của toast notification, bạn cần xóa cache trình duyệt.

📝 Hướng dẫn xóa cache:

  1. Windows/Linux: Nhấn Ctrl + Shift + R
  2. Mac: Nhấn Cmd + Shift + R
  3. Hoặc: Nhấn F12 → Click chuột phải vào nút reload → Chọn "Empty Cache and Hard Reload"

✨ UI mới của Toast:

  • ✅ Toast gọn hơn (300-380px thay vì 350-450px)
  • ✅ Message ngắn hơn, rõ ràng hơn
  • ✅ Icon X nhỏ gọn với Font Awesome
  • ✅ Line-clamp 2 dòng cho message dài
  • ✅ Padding và spacing tối ưu
